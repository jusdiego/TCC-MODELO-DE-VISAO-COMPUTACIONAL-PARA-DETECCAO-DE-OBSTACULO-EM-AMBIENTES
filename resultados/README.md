# Evidências dos resultados

`experimentos/11/` até `experimentos/24/` reúne tabelas e registros originais dos pacotes recuperados; não há experimento de treino 22 nessa pasta, porque 22 é preparação e seu pacote próprio não foi localizado. `iniciais/` contém tabelas e configurações dos ciclos anteriores. Os nomes recebidos com sufixos foram preservados em nomes de arquivo normalizados; o catálogo registra a origem.

A [análise dos resultados](../docs/03_resultados.md) apresenta as comparações com seus escopos. [resumo_final.json](resumo_final.json) é um resumo derivado para consulta; os arquivos originais de cada experimento são a fonte de referência.

O repositório contém as evidências tabulares e registros principais. Relatórios HTML, galerias, previsões completas e outros arquivos auxiliares continuam no pacote `TCC_Resultados_Para_Apresentacao.zip`, destinado ao Release. Os manifestos internos dos pacotes históricos podem citar pesos/arquivos não incluídos nesta seleção; usar `auditoria/catalogo_origens.csv` e `SHA256SUMS` para conferir esta cópia.

Não comparar diretamente porcentagens de detector, alertas, mAP ou bases distintas. O 20 usa alertas sob cobertura parcial; o 24 tem um desfecho principal micro do detector com 12 classes.
